# Voice-over Shorts

Stem Pauline. Opnieuw genereren: `bash scripts/genereer-voiceover-shorts.sh`.
De fragmenten staan in `public/voiceover-shorts/<naam>/`.

Elke Short is één regel en één eigen voorbeeld. Geen boekopgaven.

## Machtsregel

f(x) = 3x⁴, dus f′(x) = 12x³.

1. Hoe differentieer je drie x tot de vierde?
2. De machtsregel. Zo differentieer je een macht van x.
3. De functie f van x is drie x tot de vierde.
4. Haal de macht naar voren, en haal er één af.
5. Vier keer drie is twaalf. Vier min één is drie.
6. De afgeleide van f is twaalf x tot de derde.
7. Oefen het zelf op afgeleideoefenen punt nl.

## Kettingregel

f(x) = (2x + 1)³. h(x) = 2x + 1, g is de derde macht.
f′(x) = 3(2x + 1)² · 2 = 6(2x + 1)².

1. Hoe differentieer je, haakje twee x plus één, tot de derde?
2. Zit er een functie in een functie? Dan gebruik je de kettingregel.
3. De functie f van x is, haakje twee x plus één, tot de derde. De binnenkant noemen we h van x. De buitenkant is g: tot de derde.
4. Eerst de buitenkant. Drie keer, haakje twee x plus één, tot de tweede.
5. Dan keer de afgeleide van h. Die is twee.
6. De afgeleide van f is zes keer, haakje twee x plus één, tot de tweede.
7. Oefen de kettingregel op afgeleideoefenen punt nl.

## Productregel

f(x) = x² · (3x + 1). g(x) = x², h(x) = 3x + 1.
f′(x) = 2x · (3x + 1) + x² · 3 = 9x² + 2x.

1. Hoe differentieer je x kwadraat, keer haakje drie x plus één?
2. Twee functies keer elkaar? Dan de productregel.
3. De functie f van x is x kwadraat, keer haakje drie x plus één.
4. g van x is x kwadraat. h van x is drie x plus één.
5. De afgeleide van g is twee x. De afgeleide van h is drie.
6. Twee x keer haakje drie x plus één, plus x kwadraat keer drie.
7. Dat is negen x kwadraat plus twee x.
8. Oefen de productregel op afgeleideoefenen punt nl.

## Quotiëntregel

f(x) = x / (x + 1). g(x) = x, h(x) = x + 1.
Teller: (x + 1) − x = 1. Noemer blijft (x + 1)².
f′(x) = 1 / (x + 1)².

1. Hoe differentieer je x, gedeeld door x plus één?
2. Een breuk van twee functies? Dan de quotiëntregel.
3. De functie f van x is x, gedeeld door x plus één.
4. g is de teller: x. h is de noemer: x plus één.
5. In de teller staat een min. Eén keer x plus één, min x keer één. Dat is één.
6. De noemer blijft h in het kwadraat. De afgeleide van f is één, gedeeld door haakje x plus één, in het kwadraat.
7. Oefen de quotiëntregel op afgeleideoefenen punt nl.

## Wortel

f(x) = √x = x^(1/2) voor x > 0.
f′(x) = (1/2) x^(−1/2) = 1 / (2√x).

1. Hoe differentieer je wortel x?
2. De afgeleide van een wortel. Schrijf hem eerst als een macht.
3. De functie f van x is wortel x. Dat is x tot de macht een half. Dat geldt voor x groter dan nul.
4. De machtsregel: een half, keer x tot de macht min een half.
5. Terugschrijven geeft één, gedeeld door twee wortel x.
6. Oefen wortels op afgeleideoefenen punt nl.
